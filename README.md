# wheatsplitter
This is a custom split ortholinear mechanical keyboard. I built this project to qualify for Outpost and to further my PCB, CAD, and coding skills. I was also interested in building this keyboard because I worked on Hackpad last summer, and wanted to continue building keyboard-type projects. This project taught me a lot about PCB design, especially since my last PCB was done in December. I also learned a lot about the specifics on how keyboard matrixes work, which was very interesting.
